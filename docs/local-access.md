# 当前 NAS 局域网访问

前后端由同一个 Docker 容器提供，部署于 `/volume2/docker/mailnest`，访问 `http://192.168.91.85:5173`。这是 NAS 默认网络接口的地址；浏览器所在设备需要能访问该网段。不要在另一台电脑使用 `localhost:5173`，那会指向该电脑自身。

Docker Compose 使用 `compose.yml` 与本机 `compose.override.yml`，后者来自仓库的 `deploy/compose.nas.yml`。容器自动重启，`.env` 与持久化 `data/` 位于部署目录；登录密码、邮箱配置、加密密钥和原有会话从旧服务保留。原 `mailnest-lan.service` 已停用，工作区仍保留用于开发和回退。

```sh
cd /volume2/docker/mailnest
docker compose ps
docker compose restart mailnest
docker compose logs --tail=50 mailnest
```

更新部署目录的源码后执行 `docker compose up -d --build`。运行期间不要另启旧 systemd 服务或默认的 `npm run dev`，以免 5173 端口冲突或重复同步。数据备份、源码更新与回退步骤见 [部署文档](deployment.md)。当前 HTTP 地址用于局域网访问，PWA 安装和后台推送使用该文档中的 HTTPS 配置。

## 安装入口与当前地址的限制

邮件页面顶部始终提供“安装应用”按钮，“设置 → 应用与提醒”中也有入口。支持安装且浏览器已提供安装事件时，点击会显示原生安装窗口；尚未提供事件或浏览器不支持时，点击显示设备对应的手动操作说明。应用通过独立窗口打开或收到安装完成事件后，按钮会显示“已安装”。

在当前 `http://192.168.91.85:5173` 地址访问时，按钮显示 HTTP 限制说明；浏览器若提供“添加到主屏幕”或创建快捷方式，可以先作为访问入口使用。这个 HTTP 地址不启用 Service Worker，快捷方式不提供离线启动和后台邮件推送。要使用完整 PWA，需先配置设备信任的 HTTPS 地址，再从该地址重新打开页面并安装。`localhost` 的开发例外只适用于浏览器所在设备本机，NAS 的局域网 IP 不属于该例外。[MDN 安装要求](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)

界面采用简约液态玻璃风格：侧栏与浮层为冷白半透明玻璃，列表、阅读区与默认正文底色为纯白。保留紧凑布局和蓝色状态提示；浏览器不支持模糊或启用减少透明度时自动降级为不透明背景。

桌面宽屏使用邮箱导航、邮件列表和阅读区三栏，未选中邮件时阅读区显示提示。两条分隔线可以拖动，宽度保存在当前浏览器；双击恢复该栏默认宽度，聚焦后也可用左右方向键调整。邮件列表独立滚动并保留位置，阅读区占用剩余宽度，窗口变窄时自动适配。平板窄屏与手机按设备宽度切换列表或正文，星标按钮独立可点击，统一邮箱与单账号筛选方式相同。顶部将文件夹信息与回复 / 转发 / 删除 / 标记放在同一栏，标记菜单包含已读 / 未读及星标，更多菜单提供归档。发件人、主题、收件人压缩为三行；较窄阅读区的安装和提醒入口位于更多菜单，手机保留安装按钮。展开收件人可查看完整地址、抄送、主题与日期。顶部和邮件信息随正文一起滚动；打开新邮件从顶部开始，返回列表恢复位置。正文默认底色跟随系统阅读区，邮件内部原有卡片与品牌背景保留。HTML 保留原邮件排版，图片自动加载，按实际高度展示；宽表格局部横向滚动，不撑宽应用界面。

## 邮件连接使用代理 Fake-IP

当前 NAS 的 mihomo DNS 将 QQ 邮件服务器解析到 `198.18.0.0/15` 的 Fake-IP 地址。部署使用宿主网络和 NAS 的本机 DNS，`.env` 保留 `ALLOW_PRIVATE_MAIL_HOSTS=true`，允许 IMAP / SMTP 使用这些地址，由现有透明代理处理连接。该设置在重建容器后加载，也会允许其他私有 / 保留邮件服务器地址；TLS 证书、域名验证和登录鉴权继续生效，不会自动新增代理服务或规则。是否直连或走代理取决于 NAS 的代理配置。

此配置适用于当前可信用户使用的 NAS。后续若向其他用户开放，需重新评估内网访问权限；默认部署配置仍为 `false`。该开关只影响邮件连接，不改变 Web Push 等其他请求的地址校验。

转发会使用原邮件的邮箱，收件人需重新填写，正文以可编辑纯文本引用发送；原附件默认保留，可在发送前移除。附件只在点击发送时载入，失败保留草稿，合计上限为 20 个 / 20 MiB。

侧栏为“所有邮箱”和每个账号分别提供独立文件夹分组，可单独折叠。打开或刷新页面时，“所有邮箱”默认展开，各账号默认折叠；移除顶部品牌区，直接显示写邮件按钮，手机关闭导航按钮与其并排。合并目录按用途汇总，账号目录使用远端真实路径；自定义文件夹留在所属账号下，目录列表读取本地同步缓存。切换目录 / 账号会清空搜索并回到第一页。侧栏底部仅保留设置，不再显示管理员卡片；系统按个人使用设计，登录密码、API 令牌及退出登录仍在设置中管理。

已连接邮箱可在“设置 → 邮箱管理”点击编辑图标修改，密码 / 授权码留空保留原值；保存连接配置前会验证，失败保留原配置。Google 授权邮箱支持修改名称、颜色与重新授权。更改邮箱地址、IMAP 主机或登录用户名会重新同步本地缓存；其他修改保留缓存。
